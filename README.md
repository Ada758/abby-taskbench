# Abby 学习工作台

小学生二年级学习打卡工作台，四大任务栏：语文、数学、英语、游戏。

## 功能

- **语文**：课文朗读、生字笔顺、练习册、课外读物（10项子任务）
- **数学**：7个知识点，每个配动画+图解+10道交互练习题
- **英语**：Big Muzzy 12集，双栏布局（视频+跟读），每集配练习题
- **游戏**：积分兑换 Minecraft 游戏时间
- **古文观止**：每日一句（36句轮换）
- **积分系统**：完成作业+10分，全科完成+50分，50分=15分钟游戏时间
- **PWA支持**：离线缓存，移动端适配
- **数据持久化**：localStorage，每日重置

## 使用

用浏览器直接打开 `index.html` 即可使用。
